# Power Monitor Server 1.0.46

## Enable headless OTA installation

- Treats the enrolled ESP32-S3 target alias `esp32s3` as compatible with the
  canonical firmware-image target `esp32-s3`.
- Evaluates a release against the enrolled device protocol instead of forcing
  every release through the legacy `pm-protocol/1.0.0` compatibility gate.
- Keeps legacy devices constrained to their existing protocol while allowing
  `pm-agent/2.0.0` headless releases to target headless sensors.

This correction enables the Install control after firmware 2.0.4 has passed
server verification for an online headless sensor.
