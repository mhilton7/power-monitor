# Power Monitor Server 1.0.50

## Sensor assignment and active billing cleanup

- Adds an explicit sensor unassignment action to the Sensors settings workflow.
- Clears circuit, electric-service, Home-total, direct monitoring-group, and
  sensor-backed usage-authority relationships when a sensor is unassigned or
  removed, while preserving immutable historical readings.
- Closes active site-assignment windows during removal or transfer and marks
  affected open billing cycles for reviewed recalculation.

## Coordinated reset and headless sensor state

- Reconciles reported headless configuration revisions so completed desired and
  effective configuration transitions no longer block an approved data reset.
- Preserves the reset mutation barrier for genuinely pending configuration
  changes.
- Carries forward the current headless storage evidence and diagnostics repairs.

## Production frontend promotion

- Promotes the completed replacement frontend into the canonical `frontend/`
  build path and removes the superseded `frontend-next/` duplicate.
- Updates Docker, release reporting, contract tooling, documentation, unit
  coverage, browser coverage, and production bundle verification to use the
  canonical frontend path.
