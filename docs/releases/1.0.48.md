# Power Monitor Server 1.0.48

## Restore headless sensor hardware evidence and billing authority

- Persists canonical PZEM, microSD, Wi-Fi, sequence, resource, and live
  electrical evidence from headless sensor heartbeats.
- Displays live voltage, current, power, power factor, frequency, PZEM health,
  and microSD health without silently replacing valid device data.
- Repairs stale billing-authority selections, validates service-leg topology,
  and reports precise blockers when monitored usage cannot be calculated.
- Adds an append-only migration and a bounded diagnosis/repair utility without
  deleting readings, changing sensor credentials, or resetting hardware energy.

Install the digest-pinned TrueNAS YAML for this release before relying on the
new hardware evidence or billing-authority reconciliation behavior.
