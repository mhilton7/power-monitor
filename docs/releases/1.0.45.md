# Power Monitor Server 1.0.45

## Headless firmware upload compatibility

- Validates `power_monitor_sensor_headless` application images against their
  native `pm-agent/2.0.0` marker instead of the legacy browser-device protocol.
- Persists the detected agent protocol as the firmware release compatibility
  range, allowing the release to target enrolled headless sensors.
- Retains strict ESP32-S3 image, descriptor, checksum, project-name, semantic
  version, size, and appended SHA-256 validation.

Together with the headless project-name deployment setting, this allows
firmware 2.0.4 to be uploaded and deployed through the server UI.
