# Power Monitor Server 1.0.47

## Restore a single production release identity

- Republishes the API, worker, migration, frontend, and backup workloads under
  one new immutable version so TrueNAS cannot retain a stale 1.0.45 frontend
  beside the 1.0.46 backend.
- Produces a digest-pinned TrueNAS deployment YAML with matching application
  image versions for every service.
- Preserves the existing database migration head, device credentials, firmware
  releases, sensor enrollment, readings, and local storage datasets.

After installing the replacement YAML, System Health must report frontend and
backend version `1.0.47` before another sensor OTA deployment is started.
