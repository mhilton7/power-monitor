# Power Monitor Server 1.0.43

## Headless OTA readiness recovery

- Preserves enrollment-time OTA capability evidence when signed headless
  heartbeats refresh runtime capabilities.
- Validates and persists the complete signed OTA capability reported by newer
  headless firmware, allowing devices whose prior record was erased to recover
  without re-enrollment.
- Records headless agents as not requiring a microSD card when a heartbeat must
  recreate a missing capability row.
- Continues to classify boolean-only legacy OTA claims conservatively while
  retaining previously validated enrollment evidence.

This hotfix corrects the misleading `bootstrap required` status for connected
headless sensors that support authenticated server-managed OTA.
