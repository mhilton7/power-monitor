## TrueNAS deployment

The rendered production YAML uses immutable linux/amd64 image digests and keeps
PostgreSQL at exactly:

```yaml
volumes:
  - /mnt/Apps/Power/postgres:/var/lib/postgresql/data
```

Only the Caddy gateway publishes the configured host port (TCP 8443 by
default). Upgrade and rollback remain governed by the verified logical backup,
TrueNAS ZFS snapshot, and digest-pinned image procedures.
