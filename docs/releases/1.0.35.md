# Power Monitor Server 1.0.35

## Release identity

- Server version: `1.0.35`
- Alembic head: `20260803_0030`
- Device protocol: `pm-protocol/1.0.0` (unchanged)

Version 1.0.35 repairs long-range History behavior without changing the
device protocol, database schema, rate engine, or frontend contract.

## History reliability

- Preserves missing tier-recalculation evidence when PostgreSQL combines
  independently queried measurement and cost accumulators.
- Tracks tier allocation matches per sensor and exact cost window so rolling
  partial-hour and partial-day ranges remain equivalent to the raw immutable
  reading calculation.
- Adds production-scale PostgreSQL regressions for aligned and rolling 7-day
  and 30-day cost History queries.
- Records sanitized `http_request_failed` events with request correlation and
  exception type while continuing to exclude request bodies, credentials,
  cookies, signatures, and query strings.

## TrueNAS deployment

The production target remains linux/amd64 with only Caddy publishing TCP 8443.
PostgreSQL remains mounted at `/mnt/Apps/Power/postgres`.
