# Power Monitor Server 1.0.49

## Truthful headless microSD storage evidence

- Preserves canonical sequence and backlog evidence from current headless
  firmware while retaining compatibility with legacy heartbeat field names.
- Derives a healthy or threshold-based pressure state when current firmware
  reports free space but omits the optional pressure label.
- Treats `healthy`, `ok`, and `none` storage states as non-errors instead of
  presenting a critical last-error notice.
- Labels binary storage units as KiB, MiB, and GiB and also shows decimal GB for
  card capacity, so an 8 GB-class card is no longer mislabeled as 7.26 GB.
- Displays unavailable storage inventory as unavailable rather than inventing
  zero eligible, protected, event, artifact, cleanup, or dropped-record counts.
- Updates the release defaults to the current append-only Alembic head
  `20260806_0033`.

Install the digest-pinned TrueNAS YAML for this release to deploy the matching
API and Web UI images together.
