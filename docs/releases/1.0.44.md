# Power Monitor Server 1.0.44

## UI OTA recovery for existing headless sensors

- Reconstructs the fixed `pm-agent/2.0.0` ESP32-S3 OTA capability from the
  authenticated boolean claim emitted by firmware 2.0.0 through 2.0.3 when an
  older server has already erased the enrollment-time details.
- Keeps the stricter structured capability validation introduced in 1.0.43 for
  firmware 2.0.4 and later.
- Allows an online 2.0.3 sensor showing `bootstrap required` to become ready for
  its next firmware update through the server UI without another USB flash.
