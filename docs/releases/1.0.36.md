# Power Monitor Server 1.0.36

- Server version: `1.0.36`
- Device protocol: `pm-protocol/1.0.0` (unchanged)

Version 1.0.36 supersedes the image-free 1.0.35 publication attempt. The
1.0.35 source and release-evidence tags remain immutable; no 1.0.35 container
image was published.

This release retains the long-range History repairs from 1.0.35 and makes the
PostgreSQL performance gate portable across local and shared Linux runners.
The 30-day tiered-cost query remains subject to a two-second absolute warm-run
ceiling and an independent minimum 70% latency reduction requirement against
the documented pre-optimization baseline.

The 1.0.36 GitHub publication stopped during source validation before container
images were built or published. Its tag remains immutable and must not be used
for deployment; version 1.0.37 supersedes it.
