# Power Monitor Server 1.0.37

- Server version: `1.0.37`
- Device protocol: `pm-protocol/1.0.0` (unchanged)

Version 1.0.37 supersedes the image-free 1.0.35 and 1.0.36 publication
attempts. Their source and release-evidence tags remain immutable; no 1.0.35
or 1.0.36 application container images were published.

This release retains the long-range History repairs and PostgreSQL summary
optimizations while making two validation checks deterministic across local
and shared Linux runners:

- Raw History regression coverage now recognizes intentionally null gap buckets
  without converting missing measurements to zero.
- The rolling seven-day tiered-cost benchmark allows shared-runner scheduling
  variance while retaining both a strict absolute ceiling and the independent
  minimum 70% latency reduction requirement against raw immutable readings.
