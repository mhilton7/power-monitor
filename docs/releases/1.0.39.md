# Power Monitor Server 1.0.39

- Server version: `1.0.39`
- Device protocol: `pm-protocol/1.0.0` (unchanged)
- Coordinated data-reset protocol: `data-reset/1.0.0`
- Reset-capable sensor firmware: `1.0.18`

Version 1.0.39 supersedes the attempted 1.0.38 container publication with a
fresh immutable image version. It contains the coordinated administrator-only
data reset, repeat-reset NVS capacity safeguards, and preservation boundaries
documented for 1.0.38.

This version also includes the PostgreSQL release-gate correction that acquires
the device mutation lock before inserting the authenticated request nonce. The
consistent lock order prevents concurrent signed firmware operations from
deadlocking while they enter the data-reset mutation barrier. Migration test
expectations are synchronized with Alembic head `20260806_0031`, its 108-table
schema, and the added `system.data_reset` administrator permission.

The complete local release matrix passed for the unchanged application source:
445 backend tests (one deployment-only skip), 168 frontend unit tests, the full
Playwright acceptance matrix, dependency audits, SBOM generation, Linux image
builds, and the isolated seven-service TrueNAS workflow. The deployed workflow
verified three devices, 90 readings, all five encrypted backup artifacts,
replace-all behavior, and clean restore at migration `20260806_0031`.

Do not promote the images until the three GHCR references are recorded by exact
