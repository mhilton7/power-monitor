# Power Monitor Server 1.0.40

- Server version: `1.0.40`
- Device protocol: `pm-protocol/1.0.0` (unchanged)
- Database migration: `20260806_0031`
- Reset-capable sensor firmware: `1.0.18`

Version 1.0.40 carries forward the coordinated data-only reset and PostgreSQL
lock-order correction from 1.0.39. It restores direct immutable image
publication after the mandatory local release gate has generated and committed
verified release evidence.

The tag workflow retains release-identity validation, source-commit ancestry,
application-source immutability, protocol and migration checks, GHCR tag-reuse
rejection, OCI revision/version labels, maximum provenance, and SBOM generation.
It no longer repeats backend, PostgreSQL, frontend, or duplicate image-build
validation on scarce GitHub-hosted runners; each component is built and pushed
once after preflight.

The application source was already validated locally with 445 backend tests,
168 frontend tests, the full Playwright matrix, dependency audits, image builds,
and the isolated seven-service TrueNAS backup/restore workflow.
