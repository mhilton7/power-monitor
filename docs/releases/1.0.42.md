# Power Monitor Server 1.0.42

## Headless enrollment without installed peripherals

- Allows `pm-agent/2.0.0` sensors to enroll while truthfully reporting that the
  microSD card is not currently present or required.
- Preserves the operational-microSD enrollment requirement for legacy
  `pm-protocol/1.0.0` devices.
- Persists the headless sensor's reported storage requirement instead of
  forcing the capability to `sd_required=true`.
- Keeps missing-card state visible through signed heartbeat health after
  enrollment; no production measurement or storage state is fabricated.

This hotfix unblocks direct USB provisioning while the PZEM and microSD are
physically disconnected.
