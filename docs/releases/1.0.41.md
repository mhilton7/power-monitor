# Power Monitor Server 1.0.41

- Server version: `1.0.41`
- Device protocol: `pm-protocol/1.0.0` (unchanged)
- Headless agent protocol: `pm-agent/2.0.0`
- Database migration: `20260806_0032`
- Headless ESP32-S3 firmware: `2.0.0`

Version 1.0.41 adds the server and browser support required by the outbound-only
ESP32-S3 headless agent. It includes signed enrollment, heartbeat, batch and
command routes, durable boot/counter replay protection, reset and OTA command
coordination, and the matching Settings sensor controls.

The browser continues to call only this server. Device credentials and signing
material are not returned to frontend code, and the shared interoperability
identifier remains `pm-protocol/1.0.0`.

At the operator's request, this publication run generates release metadata,
builds the three production images, and renders the digest-pinned TrueNAS YAML
without rerunning the repository test suites. The disconnected PZEM and microSD
remain a separate physical validation gate.
